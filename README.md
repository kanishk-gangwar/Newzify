# 📰 Jetpack Compose News App

This is a modern Android news application built using **Jetpack Compose**, **Ktor** for API calls, and **Kotlin**. The app fetches and displays news articles across multiple categories and provides an intuitive UI/UX experience.

---

## 🚀 Features

- ⚡ Built entirely with **Jetpack Compose**
- 🌐 API integration using **Ktor**
- 🗂️ Categories supported: 
  - General
  - Business
  - Entertainment
  - Health
  - Science
  - Sports
  - Technology
- 🔁 Random headline at the top refreshes every 10 seconds
- 🔍 Tap any article to view full summary
- 🌐 Click **Read More...** to open the original article in a browser
- 📱 Responsive and clean UI for a seamless reading experience
